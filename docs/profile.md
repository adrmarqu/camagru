# Profile

## Mis fotos

Iras a galeria.

Aqui estaran todas las fotos que hayas subido. Funcionara igual que la galeria. 

Además tendras un boton para eliminar la imagen. Una vez pulsado te pedira confirmacion y una vez borrada no se podra recuperar. 

## Favoritos

Iras a galeria.

Aqui estaran todas las fotos a las que les hayas dado like. Podras quitar el like, ver los comentarios y descargarla. 

Una vez que hayas quitado el like, la imagen se quedara ahi, donde podras volver a darle like si quieres. En caso de recargar la pagina, todas las imagenes a las que les hayas quitado el like no apareceran en favoritos.

## Settings

Aqui estara la configuracion. 

Estara formado por:

- Usuario: Nombre de usuario con un boton a la derecha para cambiarlo.
- Correo: Correo electronico con un boton a la derecha para cambiarlo.
- Contraseña: Tu contraseña con asteriscos con un boton a la derecha para cambiarla.
- Notificaciones: Un checkbox para preguntarte si quieres recibir notificaciones de los comentarios de tus imagenes.
- Eliminar cuenta: Un boton para eliminar tu cuenta, una vez pulsado te pedira una confirmacion. Esta accion es irreversible.

En caso de actualizar tu cuenta seras redirigido a otra ventana.

En caso de eliminar tu cuenta, todas las imagenes subidas por el usuario, asi como los comentarios y likes se borraran.
