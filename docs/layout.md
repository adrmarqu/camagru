# Header

Estara dividido en dos partes: la izquierda y la derecha.

La parte izquierda tedra el logo y el nombre de la aplicacion 'CAMAGRU', los dos formaran parte de un contenedor que contendra el link de la galeria (home).

La parte derecha tendra dos estados: conectado, desconectado.

- Conectado: Habra un link a la galeria, a la edicion de fotos, un desplegable con cuatro opciones: Mis fotos, favoritos, settings y idiomas; y un boton de logout(que sera un icono).
- Desconectado: Habra dos links, uno para registrarse y otro para logearse.
